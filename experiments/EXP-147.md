# EXP-147: Inventory-bound sign-in scheduled-task removal

Status: Experimental
Parent: EXP-002
Evidence: needs-evidence

## Variable
Remove exactly one non-allowlisted user-application scheduled task whose primary purpose is launching a user application at sign-in and whose identity is selected from an EXP-143 inventory snapshot.

## Candidate priority
Prefer Microsoft Teams, Microsoft Office/Microsoft 365 quick-launch, Logitech/Logi Options+, Logi Bolt, Logi Tune, G Hub tray, telemetry, updater, then other non-allowlisted user-application sign-in tasks.

## Qualification gate
The selected task must be present in EXP-143 evidence as a sign-in scheduled-task candidate. Before mutation, re-read the live task and require exact agreement with captured task path/name, trigger identity, principal, actions, enabled state, and exported XML hash. Reject mixed-trigger tasks and tasks associated with Windows servicing, security, credentials, accessibility, drivers, recovery, Windows Update, enterprise management, Omnissa, Windows App, Remote Desktop, or Tailscale. Reject ambiguous ownership.

## Treatment
Delete only the selected scheduled-task registration. Do not uninstall applications, delete application files, remove packages, change services, or change device-critical drivers.

## Engineering contract
Implement Check, Capture, DryRun, Apply, Verify, VerifyReboot, and Rollback. Capture exact original exported task XML, task path/name, enabled/state metadata, principal, triggers, actions, settings, XML SHA-256, machine/user/boot identity, EXP-143 inventory hash, and protected-scope observations. Emit structured JSONL events. Apply must be idempotent. Verify must prove only the selected registration is absent and protected observations are unchanged. VerifyReboot must require a later boot and prove deletion persists. Rollback must refuse overwrite on identity drift or replacement and otherwise recreate the exact captured task from original XML, then verify exact XML/state equivalence.

## Benchmark
When physical evidence is available, collect at least five matched baseline boots and five treatment boots. Report medians and dispersion for sign-in to usable desktop, first-120-second CPU and disk activity, candidate process activity, and readiness of Omnissa, Windows App, Remote Desktop, and Tailscale. Retain failed and inconclusive runs.

## Current evidence request
needs-evidence: a real EXP-143 inventory snapshot containing a qualifying scheduled-task candidate, physical HP Windows 11 execution, five baseline and five treatment boots, first-120-second attribution, protected-application readiness, later-boot persistence verification, and executed exact rollback.
